# CyberStart

A responsive cybersecurity education showcase and startup portfolio starter. Built with HTML, CSS and JavaScript; no dependencies, build process or paid assets.

## What works now

- Responsive landing page with learning roadmap, mission and FAQs.
- Introductory CIA triad lesson with a working, accessible answer check.
- Privacy notice and custom 404 page.
- Relative asset paths for GitHub Pages project sites.

The other five roadmap modules are clearly marked as planned. There are no accounts, certificates, payment systems, registration forms or saved learning progress.

## Files

| File | Purpose |
| --- | --- |
| index.html | Main site, content, roadmap and lesson |
| styles.css | Colours, typography and mobile layouts |
| script.js | Quiz feedback and footer year |
| assets/mark.svg | Original editable brand mark and favicon |
| privacy.html | Notice for the current static implementation |
| 404.html | Missing-page fallback |
| .nojekyll | Tells GitHub Pages to serve plain static files |
| GITHUB-SETUP.md | Upload, hosting, editing and troubleshooting guide |

## Preview

Open `index.html` in a browser. For an optional local server, run `python3 -m http.server 8000` from this folder, then visit http://localhost:8000. No installation is needed for ordinary file preview.

## Before publishing

CyberStart is a working brand name. Choose and check your intended name before building a real brand around it. Replace the early-stage concept wording with accurate details when ready. Add only real founder biographies, achievements, partners and credentials. No invented testimonials or accreditation claims are included.

Use GITHUB-SETUP.md for the full walkthrough. This package has not been uploaded or deployed to your GitHub account.
